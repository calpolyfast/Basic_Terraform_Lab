# Basic_Terraform_Lab
## FAST Cloud Engineer Training Repository
This is a basic introduction and training lab for the FAST Cloud Engineer Eboard Role. This lab aims to demonstrate how easy it can be deploy and preconfigure cloud resources for a FAST workshop using Terraform infrastructure as code (IaC). Please follow the lab instructions found here: https://docs.google.com/document/d/1AR6fA2x0S0png0HI7JBAOFcgbocSiNlRLZF62kBz9ls/edit?usp=sharing
